# tree-sitter-runtime

[![GitHub stars](https://img.shields.io/github/stars/aovestdipaperino/tree-sitter-runtime?logo=github&color=brightgreen)](https://github.com/aovestdipaperino/tree-sitter-runtime/stargazers)

Rust-native runtime types for tree-sitter generated parsers.

This crate provides the type definitions that Rust parsers generated by `tree-sitter generate --rust` depend on.
